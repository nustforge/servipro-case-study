# ServiPro – Enterprise B2B Procurement Platform

## 🏢 Overview

ServiPro is a B2B procurement and tender management platform designed for UK property managers and managing agents.

It digitizes the full lifecycle of building service contracts including:

- Tender creation
- Contractor invitations
- Bid submission & evaluation
- Contract awarding
- Commission billing
- Compliance tracking
- Audit history

The platform is built for long-term contract management, not one-off jobs.

---

## 🎯 Problem Statement

Property management companies currently face:

- Fragmented contractor sourcing
- Lack of transparent bidding systems
- Poor audit trails for compliance
- Manual contract tracking
- Risk of contractor bypassing (off-platform deals)

ServiPro solves this by centralizing procurement into a controlled digital ecosystem.

---

## 🧩 Core Platform Modules

### 1. Managing Agent System

- Create and publish tenders
- Invite verified contractors
- Compare bids
- Award contracts
- Track renewals
- Maintain audit logs

### 2. Contractor System

- Access tender opportunities
- Submit structured bids
- Upload compliance documents
- Manage subscription & invoices

### 3. Admin System

- Manage platform users
- Monitor revenue & commissions
- View system analytics
- Approve/reject accounts

---

## 🔄 Business Workflow

Tender Lifecycle:

1. Managing agent creates tender
2. Contractors are invited
3. Bids are submitted
4. Evaluation and comparison
5. Contract awarded
6. Commission invoice generated
7. Contract tracked until expiry

---

## 💰 Revenue Model

ServiPro uses a hybrid contractor-funded model:

- Monthly subscription (access fee)
- Commission on awarded contracts

Managing agents use the platform free of charge.

---

## 🛠 Tech Stack

- Next.js 14 (Frontend + API routes)
- TypeScript
- PostgreSQL
- Prisma ORM
- AWS S3 (file storage)
- Stripe (subscriptions + invoices)
- SendGrid (email system)

---

## 🔐 Key Principles

- UK LTD-only contractor verification
- Full audit trail for all actions
- No handling of direct client payments
- Commission protection via non-circumvention rules
- Compliance-first procurement model
